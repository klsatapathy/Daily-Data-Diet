### Day 1: Data Science vs. Data Analytics

**The Core Difference:**
- **Data Analytics:** Focuses on processing and performing statistical analysis of existing datasets. (The "What happened?")
- **Data Science:** Focuses on creating new ways of capturing and analyzing data to make predictions. (The "What will happen?")

**The Role of Python:**
Python is used in both fields, but in Data Science, we specifically use it for:
1. **Automation:** Handling massive datasets that Excel can't touch.
2. **Modeling:** Using libraries to build predictive algorithms.
