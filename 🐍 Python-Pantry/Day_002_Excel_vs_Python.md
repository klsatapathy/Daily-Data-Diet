### Day 2: When to use Excel vs. Python

**The Rule of Thumb:**
- **Use Excel for:** Quick ad-hoc analysis, data entry, and small datasets (< 100k rows).
- **Use Python for:** Automation, complex transformations, huge datasets (> 1M rows), and Machine Learning.

**Technical Comparison:**
| Feature | Excel | Python (Pandas) |
| :--- | :--- | :--- |
| **Max Rows** | ~1 Million (Slow) | Limited only by RAM (Fast) |
| **Audit Trail** | Hard to track changes | Code documents every step |
| **Automation** | Macros (VBA) - Complex | Scripts - Simple & Reusable |
